# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability within this knowledge base, please report it responsibly.

**Do NOT open a public issue for security vulnerabilities.**

Instead, please email the maintainers directly with:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

## Scope

This knowledge base contains pharmaceutical quality management knowledge. Security concerns include:

- Inaccurate regulatory information that could lead to compliance failures
- Missing citations or attribution
- Data integrity issues in structured schemas
- Potential for misuse of pharmaceutical knowledge

## Response Timeline

- Acknowledgment: Within 48 hours
- Initial assessment: Within 1 week
- Resolution: Depends on severity

## Best Practices

When using this knowledge base:

- Always verify regulatory information against primary sources
- Do not rely solely on this knowledge base for compliance decisions
- Keep local copies updated with the latest releases
- Report any inaccuracies immediately
