## 3. Equipment Qualification Lifecycle (per EU GMP Annex 15 / FDA)

### 3.1 Qualification Phases

| Phase | Activities | Deliverables | Responsibility |
|-------|------------|--------------|----------------|
| **Design Qualification (DQ)** | Define URS, Vendor assessment, Design review, Risk assessment (FMEA) | DQ Report, URS, Vendor Audit Report, Risk Assessment | Engineering, QA, User |
| **Installation Qualification (IQ)** | Verify installation per specs, Utilities, Calibration certs, Software version, Documentation | IQ Protocol, IQ Report, Certificates (material, calibration), P&ID verification | Vendor, Engineering, QA |
| **Operational Qualification (OQ)** | Test all functions at limits, Alarm/Interlock challenge, Worst-case scenarios | OQ Protocol, OQ Report, Test Scripts, Deviation Log | Vendor, Engineering, QA |
| **Performance Qualification (PQ)** | Run under actual conditions (3 batches), Process capability (Cpk≥1.33), Long-term stability | PQ Protocol, PQ Report, Process Capability Report, SOP updates | User, Engineering, QA |
| **Continued Process Verification (CPV)** | Ongoing monitoring, Trending, Annual review, Requalification triggers | CPV Plan, Trend Reports, Annual Product Review, Requalification Records | User, QA |

### 3.2 Requalification Triggers

| Trigger | Frequency | Scope |
|---------|-----------|-------|
| **Periodic** | Annual / Biennial | Critical parameters, Safety systems, Calibration |
| **Change-Driven** | Per change | Impacted functions only (risk-based) |
| **Deviation-Driven** | Post-investigation | Root cause related functions |
| **Regulatory** | As required | Specific to observation |

### 3.3 GAMP 5 Software Categories (for Computerized Systems)

| Category | Description | Validation Approach |
|----------|-------------|---------------------|
| **Category 1** | Infrastructure (OS, DB, Network) | Supplier assessment, IT controls |
| **Category 3** | Non-configured (Firmware, HMI) | Supplier audit, IQ/OQ |
| **Category 4** | Configured (SCADA, MES, LIMS, CDS) | Full lifecycle: URS, FS, DS, IQ, OQ, PQ, CSV |
| **Category 5** | Custom/Code (Custom scripts, macros) | Full lifecycle + code review, unit testing |

## 4. Equipment Criticality Classification

| Criticality | Definition | Examples | Qualification Rigor |
|-------------|------------|----------|---------------------|
| **Critical (Direct Impact)** | Direct contact with product; failure = quality risk | Reactors, Fill/finish, Compression, Coating, Sterilizers | Full IQ/OQ/PQ + CPV |
| **Major (Indirect Impact)** | Supports critical equipment; failure may affect quality | HVAC, WFI, Compressed air, Chillers, Purified water | IQ/OQ + Periodic review |
| **Minor (Support)** | No direct product contact; failure = operational | Office HVAC, Lighting, General utilities | Installation verification only |

## Usage Notes

1. **Vendor Selection**: Always perform vendor audit per ICH Q10 / EU GMP Chapter 7
2. **URS First**: Never purchase without approved User Requirement Specification
3. **Risk-Based**: Qualification scope proportional to criticality (ICH Q9)
3. **Data Integrity**: All computerized systems must comply with 21 CFR Part 11 / Annex 11
4. **Change Control**: Any modification triggers impact assessment
5. **Tech Transfer**: Equipment equivalence critical for site-to-site transfer
