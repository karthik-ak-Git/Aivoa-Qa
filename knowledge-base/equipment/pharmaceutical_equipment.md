## 1. High-Shear Granulator (HSG)

### Purpose
Wet granulation — mixing powder with binder solution to form granules.

### Also Known As
- Rapid Mixer Granulator (RMG)
- High-speed mixer granulator

### Key Components
- Mixing bowl (stainless steel)
- Main impeller (bottom)
- Chopper (side-mounted)
- Binder addition system
- Bowl cover with sight glass
- Discharge valve

### Manufacturing Stage
Granulation

### CPPs
- Impeller speed
- Chopper speed
- Granulation time
- Binder addition rate
- Binder temperature
- Bowl temperature

### Common Failure Modes
| Failure | Effect | Root Cause |
|---|---|---|
| Impeller seal leak | Product contamination | Worn mechanical seal |
| Over-granulation | Hard granules, slow dissolution | Excessive time/speed |
| Under-granulation | Powder too fine, poor flow | Insufficient binder/energy |
| Non-uniform granulation | Content uniformity issues | Poor binder distribution |
| Bowl overheating | API degradation | Excessive friction |

### Typical Deviations
- Granulation endpoint not reached within specified time
- Product temperature exceeded limit
- Impeller speed variation > 5% of setpoint
- Chopper amperage spike

### Source
ISPE Baseline Guide, Manufacturer O&M manuals

## 2. Fluid Bed Dryer (FBD)

### Purpose
Drying wet granules after wet granulation.

### Also Known As
- Fluidized bed dryer
- Fluid bed processor (if also used for coating/granulation)

### Types
- Batch fluid bed dryer
- Continuous fluid bed dryer
- Fluid bed granulator (Wurster configuration)
- Top-spray fluid bed

### Key Components
- Product bowl (removable)
- Expansion chamber
- Filter bags / cartridge filters
- Air handling unit (AHU)
- Heater
- Exhaust fan
- Temperature and airflow sensors

### CPPs
- Inlet air temperature
- Inlet air volume/velocity
- Exhaust air temperature
- Drying time
- Filter bag differential pressure
- Product bed temperature

### Common Failure Modes
| Failure | Effect | Root Cause |
|---|---|---|
| Filter bag rupture | Product loss, contamination | Worn filters, pressure spike |
| Non-uniform drying | Wet/dry pockets in batch | Poor airflow distribution |
| Over-drying | Brittle granules, electrostatic | Excessive temperature/time |
| Under-drying | Residual moisture too high | Insufficient time/airflow |
| Filter blinding | Reduced airflow | Product sticking to filters |

### Typical Deviations
- Product temperature exceeds limit
- Inlet temperature deviates > 5°C
- Drying time extended (moisture still high)
- Filter bag pressure differential high

### Source
ISPE Baseline Guide, ASME BPE

## 3. Rotary Tablet Press

### Purpose
Compressing granules into tablets.

### Also Known As
- Tablet compression machine
- Rotary tablet machine

### Manufacturers
- Fette
- Korsch
- Manesty
- Kilian

### Key Components
- Die table (rotor)
- Upper punches, lower punches, dies
- Fill cam, weight adjustment, ejection cam
- Pre-compression roll, main compression roll
- Feeder system (forced or gravity)
- Take-off blade

### CPPs
- Compression force (main + pre)
- Turret speed
- Fill depth
- Dwell time
- Feeder speed
- Punch penetration

### Common Failure Modes
| Failure | Effect | Root Cause |
|---|---|---|
| Worn punches/dies | Weight variation, defect | Mechanical wear |
| Punch binding | Sticking, picking | Poor lubrication, high friction |
| Over-compression | Tablet hardness too high | Excessive force set point |
| Under-compression | Friability issue | Insufficient force |
| Feeder blockage | Weight variation | Bridging, poor flow |

### Typical Deviations
- Weight variation out of control
- Hardness failure
- Capping/lamination observed during in-process checks
- Reject rate > 3%

### Typical Complaints
- Broken tablets (capping/lamination)
- Weight variation
- Chipped tablets
- Hardness issues

### Source
IPEC, ISPE, USP <1062>

### Manufacturers

- Exhaust air temperature
- Spray rate
- Atomization air pressure
- Pan speed
- Bed temperature
- Tablet bed movement

### Common Failure Modes
| Failure | Effect | Root Cause |
|---|---|---|
| Spray nozzle clogging | Uneven coating | Coating solution solids buildup |
| Twinning | Two tablets stuck together | Over-wetting, high spray rate |
| Picking | Coating pulls off | Under-drying, tacky coating |
| Bridging | Coating fills score line | High coating viscosity, low temperature |

- Appearance defect rate excessive
- Spray rate variation during run

### Typical Complaints
- Peeling coating
- Chipped coating
- Discolored tablets
- Taste masking failure

## 5. Capsule Filling Machine

### Purpose
Filling powder, pellets, or liquid into hard capsule shells.

### Also Known As
- Encapsulation machine
- Capsule filler

### Manufacturers
- Bosch
- MG2
- Zanasi
- IMA

### Types
- Dosator-type filler (piston-based)
- Auger-type filler
- Vacuum-type filler
- Pellet/granule filler

### Key Components
- Capsule sorter (rectifier)
- Empty capsule feed mechanism
- Body/cap separation station
- Filling station
- Tamping/compression station
- Cap replacement station
- Capsule reject station
- Capsule polisher

### CPPs
- Fill weight target
- Tamping pressure (for dosator)
- Machine speed (capsules per minute)
- Powder level in hopper

### Common Failure Modes
| Failure | Effect | Root Cause |
|---|---|---|
| Empty capsules | Undetected empty capsule | Feed sensor issue, no tamping |
| Tilted capsules | Caps not aligned | Misalignment of transfer station |
| Split capsules | Capsule shell cracking | Shell quality, humidity |
| Weight variation | Inconsistent fill | Powder flow issue, dosator wear |
| Cap lost/dented | Defective capsule | Station misalignment |

### Typical Complaints
- Empty capsules reaching patient
- Stuck capsules (won't separate)
- Powder leaking from capsule
- Capsules cracked/opened in bottle

## 6. Autoclave

### Purpose
Steam sterilization of equipment, containers, and heat-stable products.

### Also Known As
- Steam sterilizer
- Steam autoclave

### Types
- Gravity displacement autoclave
- Vacuum-assisted autoclave (pre-vacuum)
- Air-over-steam (for aqueous products)

### Key Components
- Pressure vessel (chamber)
- Steam generator
- Vacuum pump
- Cooling system
- Control system (PLC with temp/pressure/ time monitoring)
- Chamber temperature mapping sensors
- Door interlock system

### Cycle Types
- 121°C/15 minutes (standard aqueous)
- 134°C/3 minutes (porous loads)
- Custom cycles per validation

### Common Failure Modes
| Failure | Effect | Root Cause |
|---|---|---|
| Temperature distribution non-uniform | Dead spots not sterilized | Steam trap blocked, drain issue |
| Condensate removal failure | Wet load | Vacuum system issue |
| Door seal leak | Cycle abort | Worn gasket |
| Pressure control failure | Cycle abort | Control valve/ sensor failure |

### Typical Deviations
- Temperature outside ±1°C of setpoint
- Fo value below minimum
- Cycle aborted
- Biological indicator positive

## 7. Lyophilizer (Freeze Dryer)

### Purpose
Freeze-drying of heat-sensitive products (injectables, biologics).

### Also Known As
- Freeze dryer
- Freeze-drying system

### Key Components
- Drying chamber with shelves
- Condenser (ice collector)
- Vacuum system (pumps)
- Refrigeration system
- Heating/ cooling fluid circulation
- Control system

### Stages
1. Freezing (atmospheric)
2. Primary drying (vacuum, low shelf temp)
3. Secondary drying (higher shelf temp)

### Common Failure Modes
| Failure | Effect |
|---|---|
| Shelf temperature non-uniform | Batch variation in cake appearance |
| Vacuum leak | Extended drying time |
| Condenser icing | Loss of condensation capacity |
| Collapse | Product cake collapses (below Tg) |
| Melt-back | Product melts during drying |

### Typical Complaints
- Cake appearance varies
- Reconstitution time too long
- Residual moisture out of spec
- Product discoloration (oxidation)
