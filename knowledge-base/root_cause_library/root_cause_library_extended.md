## Extended Root Cause Categories

### 7.1 Management Root Causes

| Code | Root Cause | Description | Example | Prevention |
|------|------------|-------------|---------|------------|
| MGT-001 | **Resource Allocation** | Insufficient resources for task | Operator assigned multiple tasks simultaneously | Workload assessment, resource planning |
| MGT-002 | **Communication Gap** | Information not effectively communicated | Shift handover incomplete | Standardized handover procedures |
| MGT-003 | **Priority Confusion** | Unclear task priorities | Production pressure overriding quality | Clear priority matrix, management commitment |
| MGT-004 | **Training Deficiency** | Inadequate training programs | Operator not trained on new procedure | Training needs assessment, competency matrix |
| MGT-005 | **Supervision Gap** | Lack of oversight | No verification of critical steps | Supervisory checkpoints, review requirements |
| MGT-006 | **Change Management** | Poor change control | Process change without impact assessment | Robust change control process |
| MGT-007 | **Documentation Gap** | Inadequate procedures | Missing or outdated SOP | Document control system, periodic review |
| MGT-008 | **Culture Issue** | Quality culture deficiency | "Get it done" mentality | Quality culture training, management commitment |
| MGT-009 | **Vendor Management** | Poor supplier oversight | Supplier not audited regularly | Supplier qualification program |
| MGT-010 | **Continuous Improvement** | Lack of improvement initiatives | No CAPA trending analysis | Regular quality metrics review |

## Root Cause Selection Guide

### By Deviation Type

| Deviation Type | Most Common Root Causes |
|----------------|------------------------|
| **OOS Result** | Method Error, Reference Standard, Sampling Error |
| **Environmental Excursion** | Equipment Failure, HVAC Issue, Monitoring Gap |
| **Contamination** | Material Handling, Environmental Control, Cleaning Issue |

| **Equipment Failure** | Wear and Tear, Calibration Drift, Maintenance Gap |
| **Process Deviation** | Procedure Ambiguity, Process Variability, Scale-Up Issue |
