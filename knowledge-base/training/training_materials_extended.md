## Module 1: Good Manufacturing Practices (GMP) Advanced

### 1.1 GMP Principles

#### Core GMP Requirements
| Principle | Description | Implementation |
|-----------|-------------|----------------|
| **Personnel** | Trained, qualified personnel | Training records, competency assessment |
| **Premises** | Suitable, maintained facilities | Cleaning, environmental monitoring |
| **Equipment** | Properly designed, calibrated | IQ/OQ/PQ, calibration program |
| **Materials** | Controlled starting materials | approved suppliers, testing |
| **Documentation** | Complete, accurate records | Batch records, SOPs |
| **Production** | Controlled processes | Validated processes, in-process controls |
| **Quality Control** | Adequate testing | OOS/OOT investigation |
| **Self-Inspection** | Regular audits | Internal audit program |

### 1.2 GMP Documentation Hierarchy

```
Quality Policy
    ↓
Quality Manual
    ↓
Standard Operating Procedures (SOPs)
    ↓
Work Instructions (WIs)
    ↓
Forms and Records
```

### 1.3 GMP Compliance Checklist

| Requirement | Status | Evidence |
|-------------|--------|----------|
| Quality System established | ☐ | Quality Manual |
| Management responsibility defined | ☐ | Org chart, RACI |
| Resource management in place | ☐ | Personnel, facilities |
| Product realization planned | ☐ | VMP, protocols |
| Measurement/analysis/improvement | ☐ | CAPA, metrics |

## Module 2: Quality Risk Management (QRM)

### 2.1 ICH Q9 Framework

#### Risk Management Process
```
Risk Assessment
    ↓
Risk Analysis
    ↓
Risk Evaluation
    ↓
Risk Control
    ↓
Risk Review
```

### 2.2 Risk Assessment Tools

| Tool | Application | Complexity |
|------|-------------|------------|
| **FMEA** | Process/product failure modes | High |
| **FTA** | Root cause analysis | Medium |
| **HACCP** | Food safety, pharmaceutical | Medium |
| **PHA** | Preliminary hazard analysis | Low |
| **FTA** | Fault tree analysis | High |

### 2.3 Risk Scoring Matrix

| Severity | Probability | Risk Score | Risk Level |
|----------|-------------|------------|------------|
| 1 - Negligible | 1 - Rare | 1 | Low |
| 2 - Minor | 2 - Unlikely | 4 | Low |
| 3 - Moderate | 3 - Possible | 9 | Medium |
| 4 - Major | 4 - Likely | 16 | High |
| 5 - Critical | 5 - Almost Certain | 25 | Critical |

### 2.4 Risk Mitigation Strategies

| Risk Level | Action Required | Timeline |
|------------|-----------------|----------|
| **Low** | Accept, monitor | Ongoing |
| **Medium** | Mitigate, implement controls | 30 days |
| **High** | Immediate action, escalation | 7 days |
| **Critical** | Stop, immediate correction | Immediately |

## Module 3: Deviation Management

### 3.1 Deviation Classification

| Type | Definition | Investigation | CAPA |
|------|------------|---------------|------|
| **Critical** | Affects product safety/efficacy | Full investigation | Required |
| **Major** | Significant GMP impact | Detailed investigation | Required |
| **Minor** | Limited impact | Abbreviated | As needed |

### 3.2 Deviation Investigation Process

```
Deviation Detection
    ↓
Initial Assessment (24 hours)
    ↓
Classification (Critical/Major/Minor)
    ↓
Investigation
    ↓
Root Cause Analysis
    ↓
CAPA Development
    ↓
Implementation
    ↓
Effectiveness Check
```

### 3.3 Root Cause Analysis Tools

| Tool | Description | When to Use |
|------|-------------|-------------|
| **5 Whys** | Sequential questioning | Simple issues |
| **Fishbone Diagram** | Cause-effect analysis | Complex issues |
| **Pareto Analysis** | 80/20 rule | Trending |
| **Fault Tree Analysis** | Systematic analysis | Critical issues |

## Module 4: CAPA Management

### 4.1 CAPA Process Flow

```
Problem Identification
    ↓
Root Cause Analysis
    ↓
Action Plan Development
    ↓
Implementation
    ↓
Effectiveness Verification
    ↓
Closure
```

### 4.2 CAPA Effectiveness Criteria

| Criterion | Measurement | Acceptance |
|-----------|-------------|------------|
| **Problem Recurrence** | Track for 6-12 months | Zero recurrence |
| **Metric Improvement** | Baseline vs. post-CAPA | ≥20% improvement |
| **Compliance** | Audit findings | No repeat findings |

### 4.3 CAPA Documentation

| Document | Content | Responsibility |
|----------|---------|----------------|
| **CAPA Form** | Problem, root cause, actions | Initiator |
| **Action Plan** | Tasks, owners, timelines | CAPA Owner |
| **Effectiveness Check** | Verification data | QA |
