## Priority 1: Regulatory & Standards Bodies

### 1. FDA (U.S. Food and Drug Administration)
- **URL**: https://www.fda.gov
- **Description**: Primary U.S. pharmaceutical regulator. Enforces FD&C Act, publishes CFRs, guidance documents, warning letters, and recall notices.
- **Key Sections**:
  - Drugs: https://www.fda.gov/drugs
  - CDER: https://www.fda.gov/cder
  - Guidance Documents: https://www.fda.gov/regulatory-information/search-fda-guidance-documents
- **Relevant Regulations**: 21 CFR 210, 21 CFR 211, 21 CFR Part 11
- **Access**: Public, no API key required
- **Date Retrieved**: 2026-07-28
- **Confidence**: 10/10

### 2. OpenFDA
- **URL**: https://open.fda.gov
- **API**: https://open.fda.gov/apis/
- **Description**: FDA's open data API providing access to drug adverse events, recall enforcement reports, product labeling, and drug product listings.
- **Key Endpoints**:
  - Drug Adverse Events: /drug/event.json
  - Drug Labeling: /drug/label.json
  - Drug NDC Directory: /drug/ndc.json
  - Enforcement Reports: /drug/enforcement.json
- **Access**: Public, no API key required, rate-limited
- **Date Retrieved**: 2026-07-28
- **Confidence**: 10/10

### 3. DailyMed (NLM)

## Source Quality Criteria

| Criteria | Standard |
|----------|----------|
| Authority | Published by recognized regulatory/scientific body |
| Accuracy | Data traceable to primary sources |
| Currency | Updated within 24 months |
| Objectivity | No commercial bias in core data |
| Completeness | Full data, not excerpts |
| Verifiability | Cross-references available |
