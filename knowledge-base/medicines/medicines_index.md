## High-Alert / High-Risk Medications (ISMP)

These medications have the highest risk of patient harm if formulation, packaging, or labeling errors occur:

1. **Insulin** (all formulations) - Potency, device failures
2. **Opioids** (all formulations) - Potency, abuse-deterrent failures
3. **Anticoagulants** (all) - Potency, dosing confusion
4. **Chemotherapy Agents** - Dosage errors, compounding
5. **Levothyroxine** - Narrow therapeutic index
6. **Digoxin** - Narrow therapeutic index
7. **Warfarin** - Narrow therapeutic index
8. **Phenytoin** - Narrow therapeutic index
9. **Theophylline** - Narrow therapeutic index
10. **IV Electrolytes** (K+, Mg++, Ca++) - Concentration errors
