## 8. Data Integrity Framework (ALCOA+)

### 8.1 ALCOA+ Principles
| Principle | Definition | Implementation |
|-----------|------------|----------------|
| **Attributable** | Who performed action, when | User IDs, electronic signatures, audit trail |
| **Legible** | Readable, permanent | System controls, backup, archive |
| **Contemporaneous** | Recorded at time of activity | Real-time entry, timestamp |
| **Original** | First capture or certified copy | Primary electronic record, validated copy |
| **Accurate** | Error-free, complete | Validation, review, reconciliation |
| **+ Complete** | All data including repeats | Audit trail, no deletion |
| **+ Consistent** | Logical sequence, dated | Timestamp, chronological |
| **+ Enduring** | Long-term accessibility | Archive, migration strategy |
| **+ Available** | Accessible for review | Search, retrieval, regulatory access |

### 8.2 FDA/EMA Data Integrity Expectations
| Area | Key Expectations |
|------|------------------|
| **Governance** | Senior management oversight, DI culture |
| **System Design** | Built-in controls, not retrofitted |
| **Access Control** | Unique IDs, role-based, no shared accounts |
| **Audit Trail** | Enabled, immutable, reviewed regularly |
| **Data Lifecycle** | Creation → Processing → Retention → Destruction |
| **Review** | QA review of audit trails, metadata |
| **Training** | DI awareness, role-specific |
| **Vendor Management** | SaaS/cloud DI responsibilities |

## 9. Regulatory Reporting Categories (US FDA)

### 9.1 Field Alert Reports (FAR) - 21 CFR 211.198
| Category | Timeline | Trigger |
|----------|----------|---------|
| **FAR** | 3 working days | Serious quality problem: contamination, mislabeling, potency failure, sterility failure |

### 9.2 Annual Reports - 21 CFR 314.80
| Report | Timeline | Content |
|--------|----------|---------|
| **Annual Report (NDA/ANDA)** | Annually | Summary of changes, stability, complaints, recalls |
| **Periodic Safety Update Report (PSUR)** | Per ICH E2C | Safety data summary |

### 9.3 Recall Classification
| Class | Definition | Public Notification |
|-------|------------|---------------------|
| **Class I** | Reasonable probability of serious adverse health consequences/death | Press release, public notice |
| **Class II** | Temporary/medically reversible adverse consequences | FDA Recall Notice |
| **Class III** | Unlikely to cause adverse health consequences | FDA Recall Notice |
| **Market Withdrawal** | Minor violation, no legal action | Company discretion |

## 10. Change Management Categories (FDA)

| Category | Description | Submission |
|----------|-------------|------------|
| **CBE-0** | Changes Being Effected - No Supplement | Immediate implementation, notify FDA |
| **CBE-30** | Changes Being Effected in 30 Days | Implement after 30 days, notify FDA |
| **PAS** | Prior Approval Supplement | FDA approval before implementation |
| **Annual Report** | Minor changes | Report in next Annual Report |

### Common Changes by Category
| Change | Typical Category |
|--------|------------------|
| Manufacturing site addition | PAS |
| Manufacturing process change (major) | PAS |
| Manufacturing process change (minor) | CBE-30 |
| Specification tightening | CBE-0 |
| Specification relaxation | CBE-30/PAS |
| Analytical method change (equivalent) | CBE-0 |
| Analytical method change (new) | CBE-30/PAS |
| Packaging component change (same spec) | CBE-0 |
| Packaging component change (new) | CBE-30/PAS |
| Stability protocol change | CBE-30 |
| Labeling change (safety) | CBE-30/PAS |
| Labeling change (non-safety) | Annual Report |

## 11. Inspection Readiness Checklist

### Pre-Inspection
- [ ] Site master file current
- [ ] QMS documentation organized
- [ ] CAPA metrics trended
- [ ] Deviation metrics trended
- [ ] Complaint metrics trended
- [ ] Training records current
- [ ] Vendor audit program current
- [ ] Self-inspection program current
- [ ] Data integrity assessment complete
- [ ] Mock inspection conducted

### During Inspection
- [ ] Designated escort/host
- [ ] Scribe for each inspector
- [ ] Document retrieval system ready
- [ ] SME availability confirmed
- [ ] No "off-record" conversations
- [ ] Truthful, concise answers
- [ ] Commitment tracking for follow-up

### Post-Inspection
- [ ] Form 483 response within 15 business days
- [ ] Root cause analysis for each observation
- [ ] CAPA plan with timelines
- [ ] Effectiveness verification plan
- [ ] Management review of response
- [ ] Regulatory strategy alignment
