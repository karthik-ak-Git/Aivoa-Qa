## Section 2: Manufacturing Terminology

### Processing Operations

| Term | Definition | Typical Equipment |
|------|------------|-------------------|
| **Granulation** | Agglomeration of powder particles into granules | High-shear mixer, fluid bed dryer |
| **Wet Granulation** | Granulation using liquid binder | High-shear mixer, fluid bed |
| **Dry Granulation** | Compaction without liquid (slugging/roller compaction) | Roller compactor, slugging press |
| **Direct Compression** | Compression without granulation | Tablet press |
| **Compression** | Forming tablets by powder consolidation | Rotary tablet press |
| **Coating** | Applying film/sugar/enteric layer to tablets | Coating pan, fluid bed coater |
| **Encapsulation** | Filling powder/pellets/liquid into capsules | Capsule filling machine |
| **Sterilization** | Destroying all microbial life | Autoclave, dry heat, filtration, radiation |
| **Aseptic Processing** | Sterile product in sterile environment | Isolators, RABS, cleanrooms |
| **Lyophilization** | Freeze-drying for stability | Lyophilizer |
| **Filtration** | Removing particles/microorganisms | Membrane filters, depth filters |
| **Blending/Mixing** | Homogeneous distribution of components | V-blender, ribbon blender, bin blender |
| **Drying** | Moisture removal | Fluid bed dryer, tray dryer, vacuum dryer |
| **Milling/Sizing** | Particle size reduction | Mill (hammer, pin, jet), oscillating granulator |
| **Sieving/Screening** | Particle size classification | Vibro-sifter, rotary sifter |

## Section 3: Quality & Compliance Terminology

### Deviation & Investigation

| Term | Definition | Example |
|------|------------|---------|
| **Deviation** | Departure from approved procedure/specification | Wrong temp recorded, missed sample |
| **Planned Deviation** | Pre-approved temporary change | Holiday staffing adjustment |
| **Unplanned Deviation** | Unexpected departure requiring investigation | Equipment failure, human error |
| **Critical Deviation** | May impact product quality/safety | Cross-contamination, OOS |
| **Major Deviation** | Significant impact potential | Wrong component, missing signature |
| **Minor Deviation** | Low impact, administrative | Typo in batch record, late entry |
| **Incident** | Unplanned event requiring documentation | Spill, breakage, power outage |
| **Nonconformance** | Product/material not meeting specifications | Failed assay, wrong label |
| **OOS (Out of Specification)** | Lab result outside acceptance criteria | Assay 92.0% (spec 95-105%) |
| **OOT (Out of Trend)** | Within spec but unexpected trend | Gradual assay decline over batches |
| **OOE (Out of Expectation)** | Unexpected result vs historical/predicted | New impurity detected |
| **Root Cause** | Fundamental reason for deviation | Worn gasket causing leak |
| **CAPA** | Corrective (fix) + Preventive (prevent recurrence) actions | Replace gasket + PM schedule |

### Complaint & Vigilance

| Term | Definition | Regulatory Timeline |
|------|------------|---------------------|
| **Product Complaint** | Communication about product quality defect | - |
| **Quality Defect** | Non-fulfillment of quality requirement | - |
| **Adverse Event (AE)** | Any untoward medical occurrence | - |
| **Adverse Drug Reaction (ADR)** | Noxious/unintended response at normal dose | - |
| **Serious AE** | Death, life-threatening, hospitalization, disability, congenital anomaly | Expedited (15 days) |
| **Field Alert Report (FAR)** | FDA: Serious quality problem (211.198) | 3 working days |
| **Recall** | Removal/correction of marketed product | Class I (24h), II (72h), III (30d) |
| **Market Withdrawal** | Minor violation, no legal action | - |
| **Rapid Alert** | EU: Serious quality defect notification | Immediate |

## Section 4: Analytical & Laboratory Terminology

### Test Categories

| Category | Examples | Purpose |
|----------|----------|---------|
| **Identification** | IR, UV, HPLC retention time, TLC | Confirm identity |
| **Assay/Potency** | HPLC, titration, UV spectrophotometry | Quantify API content |
| **Impurities** | Related substances, residual solvents, elemental impurities, genotoxins | Safety |
| **Physical** | Appearance, particle size, polymorphism, moisture, density | Performance |
| **Dissolution** | USP <711> apparatus 1/2/3/4/5/6/7 | Bioavailability surrogate |
| **Disintegration** | USP <701> | Breakdown in GI tract |
| **Friability** | USP <1216> | Mechanical strength |
| **Hardness** | Crushing force | Mechanical strength |
| **Weight Variation** | USP <905> | Content uniformity |
| **Content Uniformity** | USP <905> | Dosage uniformity |
| **Microbiological** | Sterility, TAMC/TYMC, specified organisms, endotoxin | Safety |
| **Stability** | ICH Q1A conditions (25/60, 30/65, 40/75) | Shelf-life |

### Method Validation Parameters (ICH Q2)

| Parameter | Definition | Typical Acceptance |
|-----------|------------|-------------------|
| **Specificity** | Ability to assess analyte in presence of interferents | Resolution >2.0, peak purity >0.999 |
| **Accuracy** | Closeness to true value | 98-102% recovery |
| **Precision** | Repeatability (intra-day), Intermediate (inter-day) | %RSD ≤2.0% |
| **Linearity** | Proportional response over range | r ≥ 0.999 |
| **Range** | Interval between upper/lower concentrations | Per specification |
| **Detection Limit (LOD)** | Lowest detectable amount | Signal/Noise ≥3 |
| **Quantitation Limit (LOQ)** | Lowest quantifiable amount | Signal/Noise ≥10 |
| **Robustness** | Reliability under small variations | ± small deliberate changes |
| **System Suitability** | System performance before analysis | Tailing ≤2.0, plates ≥2000 |

## Section 8: Validation Lifecycle

## Usage Notes

1. **Context Matters**: Many abbreviations have multiple meanings (e.g., "API" = Active Pharmaceutical Ingredient vs Application Programming Interface)
2. **Regional Variations**: Some terms differ by region (e.g., "QA/QC" roles, "Batch" vs "Lot")
3. **Evolution**: Regulatory terminology evolves (e.g., "QbD" replacing traditional approaches)
4. **Company-Specific**: Organizations may have internal acronyms not listed here
5. **Cross-Reference**: Use with regulatory documents (ICH, FDA, EMA) for full context
