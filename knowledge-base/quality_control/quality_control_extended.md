## Analytical Methods

### 1. High-Performance Liquid Chromatography (HPLC)

| Parameter | Typical Range | Application |
|-----------|---------------|-------------|
| **Column** | C18, C8, Phenyl | Reversed-phase |
| **Mobile Phase** | Water/Acetonitrile | Gradient/isocratic |
| **Flow Rate** | 0.5-2.0 mL/min | Analysis time |
| **Detector** | UV, PDA, MS | Detection |
| **Injection Volume** | 5-50 μL | Sensitivity |

### 2. Gas Chromatography (GC)

| Parameter | Typical Range | Application |
|-----------|---------------|-------------|
| **Column** | DB-5, HP-1 | Separation |
| **Carrier Gas** | He, N2, H2 | Mobile phase |
| **Temperature** | Programmed | Volatiles |
| **Detector** | FID, MS | Detection |
| **Injection** | Split/splitless | Sample introduction |

### 3. Dissolution Testing

| Apparatus | Application | Conditions |
|-----------|-------------|------------|
| **Apparatus 1** | Capsules, tablets | Basket, 50-100 rpm |
| **Apparatus 2** | Tablets | Paddle, 50-100 rpm |
| **Apparatus 3** | Modified release | Reciprocating cylinder |
| **Apparatus 4** | Modified release | Flow-through cell |

### 4. Content Uniformity

| Parameter | Acceptance |
|-----------|------------|
| **AV (Acceptance Value)** | ≤15.0 (n=10) |
| **Mean** | 85.0-115.0% of label |
| **Individual** | 75.0-125.0% of label |

## Stability Testing

### 1. ICH Stability Guidelines

| Condition | Temperature/Humidity | Duration |
|-----------|---------------------|----------|
| **Long-term** | 25°C ± 2°C / 60% ± 5% RH | 12 months |
| **Intermediate** | 30°C ± 2°C / 65% ± 5% RH | 6 months |
| **Accelerated** | 40°C ± 2°C / 75% ± 5% RH | 6 months |

### 2. Stability Test Parameters

| Test | Frequency | Acceptance |
|------|-----------|------------|
| **Appearance** | 0, 3, 6, 9, 12, 18, 24, 36 months | No change |
| **Assay** | 0, 3, 6, 9, 12, 18, 24, 36 months | 95-105% |
| **Impurities** | 0, 3, 6, 9, 12, 18, 24, 36 months | Within limits |
| **Dissolution** | 0, 3, 6, 9, 12, 18, 24, 36 months | Within spec |
| **Moisture** | 0, 3, 6, 9, 12, 18, 24, 36 months | Within spec |

## Out-of-Specification (OOS) Investigation

### 1. OOS Investigation Process

```
OOS Result Detected
    ↓
Phase I: Laboratory Investigation
    ↓
Phase II: Extended Investigation
    ↓
Root Cause Determination
    ↓
CAPA Implementation
    ↓
Final Disposition
```

### 2. Phase I: Laboratory Investigation

| Check | Action |
|-------|--------|
| **Analyst Error** | Interview analyst |
| **Method Error** | Review method |
| **Equipment Error** | Check calibration |
| **Sample Error** | Verify preparation |
| **Reference Standard** | Verify qualification |

### 3. Phase II: Extended Investigation

| Check | Action |
|-------|--------|
| **Raw Data Review** | Full data audit |
| **Instrument Logs** | Review maintenance |
| **Environmental Conditions** | Check EM data |
| **Material History** | Review incoming testing |
| **Process History** | Review batch records |

### 4. OOS Investigation Report

| Section | Content |
|---------|---------|
| **1. Product Information** | Name, batch, date |
| **2. OOS Result** | Test, result, spec |
| **3. Phase I Findings** | Laboratory investigation |
| **4. Phase II Findings** | Extended investigation |
| **5. Root Cause** | Determination |
| **6. CAPA** | Corrective actions |
| **7. Final Disposition** | Release/reject |
| **8. Approval** | Signatures |

## Method Validation

### 1. Validation Parameters

| Parameter | Definition | Acceptance |
|-----------|------------|------------|
| **Accuracy** | Closeness to true value | Recovery 98-102% |
| **Precision** | Reproducibility | RSD ≤2% |
| **Specificity** | Ability to measure analyte | No interference |
| **Linearity** | Proportional response | R² ≥0.999 |
| **Range** | Operating range | 80-120% of target |
| **LOD** | Lowest detectable | S/N ≥3:1 |
| **LOQ** | Lowest quantifiable | S/N ≥10:1 |
| **Robustness** | Method resilience | Small variations acceptable |

### 2. Method Transfer

| Activity | Responsibility |
|----------|----------------|
| **Protocol Development** | Sending unit |
| **Execution** | Receiving unit |
| **Data Analysis** | Both units |
| **Report** | Sending unit |
