## 3. Packaging Defect Taxonomy

### 3.1 Container Defects

| Defect Code | Defect Name | Description | Potential Impact | Detection Method |
|-------------|-------------|-------------|------------------|------------------|
| **CNT-01** | Cracked/Fractured Container | Visible crack in bottle/vial/ampoule | Product loss, contamination, sterility breach | Visual, Automated vision |
| **CNT-02** | Chipped Finish/Thread | Glass chip at neck/thread | Seal failure, glass particulates | Visual, Automated vision |
| **CNT-03** | Deformed Container | Out-of-round, ovality, paneling | Fill volume, label application, stacking | Dimensional, Visual |
| **CNT-04** | Delamination/Flaking (Glass) | Surface layer separation | Glass particulates in product | Visual, Polarized light |
| **CNT-05** | Container Wall Thickness Variation | Uneven distribution | Impact resistance, weight | Gauge measurement |
| **CNT-06** | Foreign Matter in Container | Glass, metal, plastic, fiber in container | Patient safety, product contamination | Visual, X-ray, Automated vision |
| **CNT-07** | Container Cleanliness Failure | Residue, oil, mold release agent | Product contamination | Visual, Swab test |
| **CNT-08** | Incorrect Container | Wrong size, material, type | Fill volume, stability, regulatory | Visual, Barcode scan |
| **CNT-09** | Container Color Variation | Amber/clear color out of spec | Light protection, brand identity | Spectrophotometer |
| **CNT-10** | Bubbles/Seeds/Stones in Glass | Inclusions in glass wall | Structural integrity, particulates | Visual, Polarized light |

## 4. Packaging Material Testing Standards

### 4.1 USP General Chapters

| Chapter | Title | Scope |
|---------|-------|-------|
| **USP <660>** | Glass Containers | Chemical durability, hydrolytic resistance |
| **USP <661>** | Plastic Packaging Systems | Physicochemical, biological tests |
| **USP <661.1>** | Plastic Materials of Construction | Material characterization |
| **USP <661.2>** | Plastic Packaging Systems for Pharmaceutical Use | System suitability |
| **USP <671>** | Containers - Performance Testing | Leakage, moisture permeation, light transmission |
| **USP <381>** | Elastomeric Closures for Injections | Fragmentation, self-seal, extractables |
| **USP <382>** | Elastomeric Closures - Functional Testing | Penetration, fragmentation, coring |
| **USP <797>** | Pharmaceutical Compounding - Sterile Preparations | Aseptic processing, container closure |
| **USP <1151>** | Pharmaceutical Dosage Forms | Performance tests for dosage forms |
| **USP <1207>** | Container Closure Integrity Testing | CCIT methods (deterministic, probabilistic) |

### 4.2 Key Test Methods

| Test | Method | Acceptance Criteria | Frequency |
|------|--------|---------------------|-----------|
| **Leak Test (Dye Ingress)** | USP <1207> / ASTM F1929 | No dye penetration | Each lot / Validation |
| **Vacuum Decay** | USP <1207> / ASTM F2338 | No pressure rise > spec | 100% in-line / Validation |
| **Helium Leak** | USP <1207> / ASTM F2391 | Leak rate < 10⁻⁶ mbar·L/s | Validation, Stability |
| **High Voltage Leak (HVLD)** | USP <1207> / ASTM F3169 | Current < threshold | 100% in-line for liquids |
| **Moisture Vapor Transmission Rate (MVTR)** | USP <671> / ASTM F1249 | Per spec (e.g., <0.1 g/m²·day) | Lot release / Stability |
| **Oxygen Transmission Rate (OTR)** | ASTM D3985 / F1927 | Per spec (e.g., <0.01 cc/m²·day) | Lot release / Stability |
| **Seal Strength (Peel/Tensile)** | ASTM F88 / F904 | Mean ≥ spec, no seal failure | Lot release / Validation |
| **Cap Torque** | USP <671> / ASTM D3198 | Application/removal torque range | 100% in-line / Lot release |
| **Child Resistance** | 16 CFR 1700.20 / ISO 8317 | ≥80% child resistant, ≥90% senior | Validation / Periodic |
| **Extractables/Leachables** | USP <661>, <1663>, <1664> | Below safety thresholds (PQRI) | Qualification / Stability |
| **Photostability** | ICH Q1B | No unacceptable change | Stability protocol |

## 5. Stability-Packaging Relationship

| Dosage Form | Critical Packaging Attributes | Stability Risks |
|-------------|------------------------------|-----------------|
| **Tablet (Immediate Release)** | Moisture barrier, light protection | Hydrolysis, oxidation, photodegradation |
| **Tablet (Enteric/MR)** | Moisture barrier, acid resistance | Premature release, dose dumping |
| **Capsule (Hard Gelatin)** | Moisture barrier (13-16% RH) | Cross-linking, brittleness, sticking |
| **Capsule (HPMC)** | Moisture barrier (lower than gelatin) | Less cross-linking risk |
| **Softgel** | Moisture/oxygen barrier, light | Oxidation, shell cross-linking, leakage |
| **Injectable (Solution)** | Container closure integrity, light | Oxidation, hydrolysis, particulate formation |
| **Lyophilized** | Stopper seal integrity, moisture | Moisture uptake, cake collapse, potency loss |
| **Ophthalmic** | Sterility assurance, preservative | Microbial growth, preservative loss |
| **Inhalation (MDI/DPI)** | Dose delivery, moisture protection | Dose variability, microbial growth |
| **Transdermal Patch** | Adhesion, drug reservoir integrity | Dose delivery, crystallization |
| **Oral Liquid** | Seal integrity, light protection | Microbial growth, oxidation, precipitation |
| **Effervescent** | Ultra-high moisture barrier | Premature reaction, gas generation |

## Usage Notes

1. **Container Closure Integrity (CCI)**: 100% inspection required for sterile products (USP <1207>)
2. **Extractables/Leachables**: Required for all new container/drug combinations (USP <1663>, <1664>, PQRI)
3. **Child Resistance**: Mandatory for OTC and specific Rx per 16 CFR 1700 / ISO 8317
4. **Tamper Evidence**: Required per 21 CFR 211.132 / EU 201/83 Art 54
5. **Serialization**: DSCSA (US), FMD (EU), and global mandates require unit-level unique identification
6. **Stability**: Packaging must be qualified for each market's climatic zone (ICH Q1A-Q1F)
7. **Change Control**: Any packaging change requires impact assessment (ICH Q9) and regulatory notification
