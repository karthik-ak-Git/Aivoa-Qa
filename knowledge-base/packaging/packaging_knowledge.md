## 1. Bottle (HDPE)

### Description
High-density polyethylene (HDPE) bottle used for solid oral dosage forms (tablets, capsules).

### Common Uses
- Tablets (IR, ER, ODT)
- Capsules (hard and soft)
- Powders
- Dry granules

### Components
- Bottle body (HDPE, PP, PET)
- Closure (child-resistant or standard)
- Inner seal (induction seal, pressure-sensitive liner)
- Desiccant canister (optional)
- Cotton or wadding (optional)
- Label

### Common Defects
| Defect | Description | Cause |
|---|---|---|
| Cracked Bottle | Hairline or visible cracks | Impact damage, material stress |
| Thread Damage | Damaged closure threads | Over-torquing, cross-threading |
| Moisture Ingress | Water vapor entering bottle | Failed induction seal, loose cap |
| Bottle Deformation | Out-of-round bottle | High molding temperature, storage |
| Flash | Excess plastic at mold line | Mold wear, injection parameter issue |

### Typical Complaints
- Tablets found crushed/powdered at bottom
- Desiccant broken inside bottle
- Cap loose/off
- Bottle leaking during shipping
- Label peeling or wrinkled

## 2. Blister Pack

### Description
A pre-formed plastic cavity sealed with lidding foil for unit-dose packaging.

### Types
| Type | Material | Use Case |
|---|---|---|
| PVC Blister | PVC + Aluminum foil | Standard tablets/capsules |
| PVC/PVDC Blister | PVC with PVDC coating | Moisture-sensitive products |
| Aclar Blister | Aclar (PCTFE) laminate | High moisture barrier |
| Cold Form Foil | Aluminum/Aluminum | Extreme moisture protection |
| Push-Through Blister | PVC + printed foil | Patient convenience |
| Peel-Push Blister | Dual layer | Child-resistant/tamper-evident |

### Components
- Forming film (bottom web): PVC, PVC/PVDC, Aclar, PP, PET
- Lidding foil (top web): Aluminum foil with heat-seal coating
- Print on foil (product name, lot, expiry)

### Common Defects
| Defect | Description | Cause |
|---|---|---|
| Pinhole in Foil | Tiny hole in aluminum foil | Foil defect, mechanical damage |
| Open Seal | Blister cavity not properly sealed | Temperature/pressure too low |
| Over-sealed | Foil melted through | Temperature too high |
| Misshapen Pocket | Deformed blister cavity | Wrong forming temperature/vacuum |
| Crushed Product | Product damaged in pocket | Pocket too small, handling |
| Incomplete Fill | Product missing from pocket | Feeder malfunction |

### Typical Complaints
- Empty blister pockets
- Blisters open before use
- Pills crushed inside blister
- Foil torn/leaking
- Cannot push tablet through foil

## 3. Bottle (Glass)

### Description
Glass bottles for liquid oral, injectable, ophthalmic, and other liquid products.

### Types
- Type I (Borosilicate): Highest chemical resistance for injectables
- Type II (Treated Soda-Lime): For acidic/neutral liquids
- Type III (Soda-Lime): For dry powders and non-aqueous liquids

### Components
- Glass bottle or vial
- Rubber stopper (for vials)
- Aluminum seal/crimp (for vials)
- Screw cap (for oral liquids)
- Dropper assembly (for eye/ear drops)
- Measuring cup (for oral liquids)

### Common Defects
| Defect | Description |
|---|---|
| Cracked Glass | Visible cracks, potential breach |
| Chip at Finish | Chipped glass at neck |
| Star Crack | Impact crack radiating from point |
| Surface Scratch | Superficial glass defect |
| Glass Particulate | Glass fragments inside container |
| Crizzle | Fine surface cracks in glass |

### Typical Complaints
- Cracked vial/ampoule
- Glass particles in liquid
- Rubber stopper defect (coring)
- Bottle breakage in shipment

## 4. Tube

### Description
Collapsible tube for semisolid products (creams, ointments, gels, pastes).

### Types
- Aluminum tube (laminated, internally coated)
- Plastic tube (HDPE, LDPE, PP)
- Laminate tube (multi-layer for barrier)

### Components
- Tube body
- Cap (screw, flip-top, or snap)
- Membrane/seal (for tamper evidence)
- Inner coating (if needed for compatibility)

### Common Defects
- Tube body splits or bursts
- Cap cross-threaded
- Missing inner membrane
- Pin-hole in tube wall
- Decoration/printing abrasion

### Typical Complaints
- Tube burst open when squeezing
- Cream separated with liquid
- Cap won't close properly
- Tube split at crimp
- Printing coming off

## 5. Sachet / Stick Pack

### Description
A small sealed pouch containing single-dose powder, granule, or liquid.

### Materials
- Paper/Aluminum/PE laminate
- PET/AL/PE laminate
- Coated paper

### Common Defects
- Leaking seals
- Pin-holes in laminate
- Delamination of layers
- Incomplete fill
- Seal contamination from product

### Typical Complaints
- Sachet leaked before opening
- Can't tear open sachet
- Product clumped inside

## 6. Carton (Folding Box)

### Description
Secondary packaging that holds primary packaged product.

### Material
- Paperboard (SBS, clay-coated)
- Corrugated (for outer shipper)
- Printed with product information

### Common Defects
- Poor print quality
- Wrong information printed
- Scored/creased incorrectly
- Glue failure (opening at seams)
- Scratched or scuffed surface

### Typical Complaints
- Carton opens at seams
- Print smudged/illegible
- Wrong product description on carton

## 7. Label

### Description
Pressure-sensitive, glue-applied, or shrink-sleeve label on primary or secondary packaging.

### Types
- Pressure-sensitive label
- Wet glue label
- Shrink sleeve label
- In-mold label
- booklet / extended content label

### Information Required (21 CFR 201)
- Product name (brand and generic)
- Drug facts / active ingredients
- Dosage strength
- Net quantity
- Manufacturer/ distributor name and address
- NDC number
- Lot number
- Expiry date
- Storage conditions
- Warnings and precautions

### Common Defects
| Defect | Description |
|---|---|
| Misaligned Label | Crooked label application |
| Wrinkled Label | Label applied with wrinkles |
| Missing Label | No label on container |
| Double Label | Two labels on same container |
| Label Mix-up | Wrong label applied |
| Ink Smear | Printing smudged/illegible |
| Bar Code Issue | Bar code not scannable |

### Typical Complaints
- Label fell off
- Can't read expiration date
- Wrong name on product
- No barcode or unreadable

## 8. Insert / Package Insert (PI)

### Description
Printed document containing detailed product information (also called prescribing information, patient information leaflet).

### Requirements (21 CFR 201.56/201.57)
- Description
- Clinical pharmacology
- Indications and usage
- Contraindications
- Warnings and precautions
- Adverse reactions
- Drug interactions
- Dosage and administration
- How supplied/storage and handling
- Patient counseling information

### Common Defects
- Missing from package
- Wrong insert (different product)
- Illegible print
- Incorrect folding
- Wrong language version

## 9. Seal (Induction / Tamper-Evident)

### Description
Inner seal providing tamper evidence and moisture barrier.

### Types
- Induction seal (foil + pulp backing)
- Pressure-sensitive liner
- Tamper-evident band (shrink band)

### Common Defects
- Missing induction seal
- Seal partially bonded
- Seal over-burned (charred)
- Seal lifting or floating
- Seal contamination

## 10. Closure / Cap

### Description
Container closure system component providing seal and access.

### Types
- Child-resistant (CR): Push-and-turn, squeeze-and-turn
- Continuous thread (CT)
- Snap cap
- Flip-top cap
- Pump cap
- Dropper cap
- Spray pump

### Common Defects
- Cracked cap
- Stripped threads
- Cross-threaded
- CR mechanism failure
- Missing liner

### Typical Complaints
- Can't open (elderly, arthritis)
- Not child-resistant enough
- Cap splits/ cracks
- Cap won't reseal

## 11. Vial (for Injectables)

### Description
Glass or plastic container for sterile injectable products.

### Types
- Single-dose vial
- Multi-dose vial
- Serum vial
- Lyophilization (freeze-dry) vial

### Components
- Glass vial
- Rubber stopper (butyl, chlorobutyl, bromobutyl)
- Aluminum flip-off seal or crimp cap

### Typical Complaints
- Cracked vial
- Stoppers falling off
- Coring (pieces of stopper in liquid)
- Difficult to open flip-off button
- Vial breakage when opening

### Description
Sealed glass container for single-dose injectable preparations.

### Types
- One-point cut (OPC) ampoule
- Two-point cut ampoule
- Ampoules with color-break rings

### Typical Complaints

- Glass particles on opening

## 13. Pre-filled Syringe

### Description
A ready-to-use syringe pre-filled with a sterile drug solution.

### Components
- Syringe barrel (glass or plastic)
- Plunger with rubber stopper
- Needle shield
- Needle (staked or luer lock)
- Tip cap

### Typical Complaints
- Stuck plunger (won't move or too hard)
- Air bubbles in syringe
- Needle shield stuck
- Liquid leaking past plunger
- Silicone oil droplets visible

## 14. IV Bag / Infusion Container

### Description
Flexible plastic bag for IV infusion products.

### Materials
- PVC (with DEHP plasticizer)
- Non-PVC (polypropylene, polyolefin)
- Multi-layer film

### Components
- Bag
- IV port (for administration set)
- Medication port (for additives)
- Overwrap (protective barrier)
- Hanger hole

### Typical Complaints
- Leaking at port or seal
- Cloudy solution
- Overwrap compromised
- Port difficult to access
- Wrong volume

## Packaging Materials Summary

| Material | Common Use | Key Concerns |
|---|---|---|
| HDPE | Bottles for tablets/capsules | Moisture vapor transmission rate (MVTR) |
| PVC | Blister forming film | Environmental concerns, MVTR |
| Aluminum | Blister foil, sachets | Pinholes, cracking |
| Glass | Bottles, vials, ampoules | Breakage, particulates |
| Rubber | Stoppers, plungers | Coring, extractables/leachables |
| Paperboard | Cartons | Moisture sensitivity |
| PET | Bottles | Oxygen transmission rate |
| PP | Caps, bottles | Thermal resistance |

**Sources**: 21 CFR 211.130 (Packaging and Labeling), USP <661> (Plastic Packaging), USP <671> (Containers), USP <1660> (Extractables/Leachables), FDA Guidance: Container Closure Systems
