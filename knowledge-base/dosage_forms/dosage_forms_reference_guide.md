## 1. Complete Dosage Form Classification

### 1.1 Oral Solid Dosage Forms

| Dosage Form | Code | Definition | Typical Use |
|-------------|------|------------|-------------|
| **Tablet, Immediate Release** | TAB-IR | Compressed solid containing API, disintegrates rapidly | Most common oral delivery |
| **Tablet, Extended Release** | TAB-ER | Controlled release over extended period | Chronic conditions, reduced dosing frequency |
| **Tablet, Delayed Release (Enteric)** | TAB-DR | Resists gastric fluid, releases in intestine | Acid-labile APIs, local intestinal action |
| **Tablet, Orally Disintegrating** | TAB-ODT | Disintegrates in saliva without water | Pediatric, geriatric, dysphagia |
| **Tablet, Chewable** | TAB-CHEW | Designed to be chewed before swallowing | Pediatric, vitamins, antacids |
| **Tablet, Effervescent** | TAB-EFF | Dissolves in water with CO2 evolution | Rapid onset, large dose volumes |
| **Tablet, Sublingual** | TAB-SL | Dissolves under tongue for buccal absorption | Rapid systemic, avoid first-pass |
| **Tablet, Buccal** | TAB-BUC | Adheres to buccal mucosa for absorption | Hormones, nicotine, analgesics |
| **Capsule, Hard Gelatin** | CAP-HARD | Two-piece shell filled with powder/pellets | Taste masking, combination products |
| **Capsule, HPMC (Vegetarian)** | CAP-HPMC | Hydroxypropyl methylcellulose shell | Vegetarian/vegan, hygroscopic APIs |
| **Capsule, Soft Gelatin** | CAP-SOFT | One-piece hermetic seal for liquids/semi-solids | Lipophilic APIs, enhanced bioavailability |
| **Caplet** | CAPLET | Tablet shaped like capsule | Easier swallowing, branding |

### 1.2 Oral Liquid Dosage Forms

| Dosage Form | Code | Definition | Key Characteristics |
|-------------|------|------------|---------------------|
| **Solution** | SOL | API dissolved in suitable vehicle | Clear, homogeneous, stable |
| **Syrup** | SYR | Concentrated sucrose solution with API | Viscous, sweet, preservative needed |
| **Elixir** | ELIX | Hydroalcoholic solution with API | Alcohol 5-40%, flavored |
| **Suspension** | SUSP | API dispersed but not dissolved | Shake well, settle, redisperse |
| **Emulsion** | EMUL | Oil-in-water or water-in-oil dispersion | Two immiscible phases, emulsifier |
| **Drops, Oral** | DROP | Concentrated liquid for drop dosing | High potency, calibrated dropper |
| **Concentrate for Oral Solution** | CONC | Dilute before administration | Reduce shipping weight |
| **Powder for Oral Solution** | POW-SOL | Reconstitute with water before use | Stability, dose flexibility |
| **Granules for Oral Suspension** | GRAN-SUSP | Granules to disperse in water | Pediatric, taste masking |
| **Oral Gel** | GEL-ORAL | Semi-solid gel for oral administration | Mucosal adhesion, local action |

## 2. Manufacturing Process Overview by Dosage Form

### 2.1 Tablets (Immediate Release)
```
Dispensing → Sifting → Granulation (Wet/Dry/Direct) → Drying → Milling/Sizing → Blending (Lubrication) → Compression → Coating (Optional) → Printing → Packaging
```
**Critical Steps:** Granulation endpoint, Blend uniformity, Compression force/weight, Dissolution

### 2.2 Tablets (Extended Release)
```
Core tablet manufacturing → Barrier/Seal coat → Drug layer (or matrix) → Rate-controlling membrane → Final coat
```
**Critical Steps:** Drug layer uniformity, Membrane integrity, Coating weight uniformity, Drug release profile

### 2.3 Hard Capsules
```
Shell qualification → Powder blending → Encapsulation (Dosing) → Polishing → Weight check → Visual inspection → Polishing → Packaging
```
**Critical Steps:** Fill weight, Weight variation, Capsule integrity, Dissolution

### 2.4 Soft Gelatin Capsules
```
Gelatin preparation → Fill preparation → Encapsulation (Rotary die) → Drying → Inspection → Polishing → Packaging
```
**Critical Steps:** Fill weight, Seal integrity, Moisture content, Dissolution, Microbial limits

### 2.5 Sterile Injectables (Aseptic)
```
Component prep (Washing/Depyrogenation) → Sterilization (Autoclave/Depyrogenation) → Aseptic Assembly → Filling → Stoppering → Crimping → Inspection → Lyophilization (if) → Packaging
```
**Critical Steps:** Media fills, Filter integrity, Fill weight/volume, Sterility, Particulates, CCIT

### 2.6 Lyophilized Products
```
Solution prep → Filtration → Aseptic filling (partial stopper) → Lyophilization (Freezing/Primary/Secondary drying) → Stoppering → Crimping → Inspection
```
**Critical Steps:** Cake appearance, Moisture content, Reconstitution time, Sterility

### 2.6 Semi-solids (Cream/Ointment/Gel)
```
Phase preparation (Aqueous/Oil) → Emulsification/Homogenization → Cooling → Deaeration → Filling → Sealing → Inspection
```
**Critical Steps:** Homogenization, Viscosity, Particle size, Microbiological quality, Fill weight

### 2.7 Transdermal Patches
```
Backing laminate → Drug reservoir coating/lamination → Rate-controlling membrane → Release liner → Die cutting → Pouching
```
**Critical Steps:** Drug content uniformity, Adhesion, Flux/permeation, Adhesive integrity

### 2.8 Inhalation (MDI)
```
Concentrate preparation → Filling (Under pressure) → Crimping → Leak testing → Actuator assembly → Labeling
```
**Critical Steps:** Dose uniformity, Particle size (MMAD/FPD), Leak rate, Spray pattern

## 3. Stability Considerations by Dosage Form

| Dosage Form | ICH Conditions | Key Degradation Pathways | Container Impact |
|-------------|----------------|-------------------------|------------------|
| **Tablets (IR)** | 25/60, 30/65, 40/75 | Hydrolysis, Oxidation, Photolysis | HDPE/PET bottles, blister (PVC/PVDC/Alu) |
| **Tablets (ER)** | Same + cycling | Polymer degradation, Dose dumping risk | Same + moisture barrier critical |
| **Capsules (Gelatin)** | 25/60, 30/65 | Cross-linking, Brittleness, Microbial | Low moisture barrier, desiccant |
| **Capsules (HPMC)** | Same | Lower cross-linking risk | Similar |
| **Softgels** | 25/60, 30/65 | Shell cross-linking, Leakage, Oxidation | Blister, oxygen barrier |
| **Injectables (Solution)** | 5°C, 25/60, 30/65 | Hydrolysis, Oxidation, Aggregation | Glass vials, stoppers, N2 overlay |
| **Lyophilized** | 5°C, 25/60, 30/65 | Moisture uptake, Cake collapse | Vials, stoppers, seal integrity |
| **Suspensions** | 25/60, 30/65 | Sedimentation, Caking, Microbial | Shake test, viscosity, microbial |
| **Emulsions** | 25/60, 30/65 | Creaming, Coalescence, Phase separation | Droplet size, zeta potential |
| **Creams/Ointments** | 25/60, 30/65, 40/75 | Phase separation, Microbial, Oxidation | Jars, tubes, pumps |
| **Transdermal Patches** | 25/60, 30/65 | Drug loss, Adhesive degradation | Foil pouches, humidity critical |
| **MDI** | 25/60, 30/65, 5°C | Propellant loss, Valve degradation | Canister, valve, actuator |
| **DPI** | 25/60, 30/65 | Moisture uptake, Flowability | Desiccant, blister, humidity control |

## 5. Common Quality Defects by Dosage Form

| Dosage Form | Top 5 Defects | Detection Method |
|-------------|---------------|------------------|
| **Tablets** | Capping, Sticking, Weight variation, Hardness variation, Dissolution failure | Visual, Weight, Hardness tester, Dissolution |
| **Capsules** | Empty, Split, Weight variation, Cross-contamination, Brittle shells | Visual, Weight, Leak test |
| **Softgels** | Leakers, Stuck twins, Shape distortion, Fill weight, Microbial | Visual, Leak test, Weight, Microbial |
| **Injectables** | Particulates, CCI failure, Sterility, Sub-visible particulates, pH | Visual, CCIT, Sterility test, HIAC, pH meter |
| **Lyophilized** | Cake collapse, Moisture high, Reconstitution time, Sterility | Visual, Karl Fischer, Reconstitution test, Sterility |
| **Ophthalmics** | Particulates, pH shift, Preservative loss, Sterility | Visual, pH, Preservative assay, Sterility |
| **Creams/Ointments** | Phase separation, Grittiness, Microbial, Weight, Viscosity | Visual, Microscopy, Microbial, Weight, Viscometer |
| **Patches** | Adhesion failure, Crystallization, Drug loss, Edge lift | Adhesion test, Microscopy, Assay, Visual |
| **MDI** | Dose uniformity, Leak rate, Particle size, Valve sticking | Cascade impactor, Leak test, Actuation |
| **DPI** | Dose uniformity, Flowability, Humidity stability, Cap dispersal | Dose uniformity, Flow tester, Stability |
