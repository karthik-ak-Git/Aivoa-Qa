## [1.0.0] - 2026-07-28

### Added

#### Knowledge Base
- 18 knowledge domains covering full pharmaceutical QMS lifecycle
- Complaint management: 14 categories, 120+ terms, 9 structured cases
- Root cause library: 6M taxonomy, 80+ root causes
- CAPA management: Full lifecycle with 7-step process and JSON schemas
- Deviation management: Classification framework and examples
- Investigation management: Phase I/II methodology and RCA methods
- Regulatory compliance: FDA 21 CFR, ICH Q7-Q12, EU GMP, WHO, USP
- FDA enforcement: 11 recall case studies (1982–2025)
- FDA warning letters: 10 analyses (2016–2025)
- Medicine database: 100+ drugs across 10 therapeutic categories
- Manufacturing: 7 stages with CPPs and failure modes
- Equipment: 25 types with maintenance schedules
- Packaging: 14 types with defect taxonomy
- Dosage forms: 24 forms with stability profiles
- Quality control: Testing procedures and OOS/OOT
- Training: Competency requirements and GMP topics
- Validation: Process, equipment, cleaning, CSV
- Supplier management: Qualification and audit programs
- Templates and forms: SOPs, CAPA records, intake forms
- Reference: 150+ term dictionary, 200+ abbreviations

#### Data Infrastructure
- 228+ source citations from 36 authoritative bodies
- 15+ JSON schemas for structured data
- Vector store standards and embedding recommendations
- Knowledge map with domain relationships
- Source index with citation tracking

#### Documentation
- Comprehensive README with project overview
- Architecture documentation
- Project structure guide
- Contributing guidelines
- Code of conduct
- Security policy
- Roadmap

#### Frontend Prototype
- React + TypeScript complaint management UI
- Express + Gemini AI backend
- AI-powered complaint extraction and risk assessment
